## Deskripsi Repository
Repository ini berisi implementasi praktikum Container Security:
1. **Lab 1:** Docker Fundamentals (Lifecycle, inspeksi container, logs, stats).
2. **Lab 2:** Container & Filesystem Vulnerability Scanning dengan Trivy.
3. **Lab 3:** Secure Dockerfile Best Practices (Multi-stage build, minimal base image, non-root user, .dockerignore).
4. **Lab 4:** CI/CD Integration dengan GitHub Actions (`security-scan.yml` & `dependency-scan.yml`).
5. **Tugas 1 - 5:** Analisis kerentanan, hardening checklist (10 item), dan Falco Runtime Security.
